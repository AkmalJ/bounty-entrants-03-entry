Entry for make.fun's "Bring the most entrants to the bounties you make" bounty. The entry is the bounty named in `BOUNTY.json`: **Funniest One-Line AI Agent Confession**, a $2 sponsor bounty launched on make.fun for this competition — one line, at most 200 characters, judged head-to-head in blind rounds, free to enter. `main.ts` validates `BOUNTY.json` and hands a verified copy to the gate at `/output/BOUNTY.json`; make.fun counts the Confession bounty's entrants in its own database.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
